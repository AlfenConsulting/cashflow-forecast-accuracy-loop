# Security

To report a vulnerability or any other problem with this plugin, email
finance@alfenconsulting.dk. Please include what you saw, the steps to
reproduce it and the version in `.claude-plugin/plugin.json`.

We read every report and reply when we have looked into it. Please do not
open a public issue for a security problem.

The plugin contains instructions only. It runs no code, has no server, does
not move money or book anything, and fetches nothing from the web.
